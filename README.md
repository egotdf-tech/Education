# БРИДЖ — пространство практики

Одностраничный локальный прототип на HTML, CSS и JavaScript. Сборка и установка пакетов не нужны. Внешние шрифты, библиотеки и сетевые сервисы не используются.

## Как открыть на компьютере

1. Скопируйте всю папку сайта на компьютер. Файлы `index.html`, `style.css`, `script.js` и папка `assets` должны лежать рядом.
2. Дважды щёлкните `index.html`: сайт откроется в браузере.
3. Если браузер ограничивает работу локальных файлов, откройте терминал в папке и выполните `python -m http.server 8000` (на macOS/Linux обычно `python3 -m http.server 8000`). Затем откройте `http://localhost:8000`. Остановить сервер: Ctrl+C.

## Что попробовать

- Уже добавлены два курса по 8 занятий. Даты демонстрации формируются относительно первого открытия.
- «Добавить курс»: код `BRIDGE-SERVICE`. Коды двух других курсов: `BRIDGE-PRO`, `BRIDGE-TALK`.
- «Настройки демо»: выберите занятие и «Во время занятия». Откроется отметка очно/онлайн.
- Выберите «Через час после занятия»: отправьте отзыв и откройте случайного персонажа. Поле «Что беру в работу» обязательно, остальные необязательны.
- Выберите личный или публичный отзыв. По умолчанию он личный. Публичность относится ко всему отзыву и переписке.
- «Через 49 часов»: форма отзывов закрывается, но разговор по уже отправленному отзыву продолжается.
- Отправьте домашнее задание. Внизу страницы, в панели организатора, нажмите «Проверить ДЗ» и поставьте «Выполнено». Ответ будет заблокирован.
- Ответьте на отзыв из панели организатора: появится уведомление студента.
- Создайте или скопируйте занятие, измените преподавателя, картинку, адрес, ссылку подключения и домашнее задание.
- «Скачать Excel»: настоящая книга `.xlsx` с листами «Посещаемость», «Домашние задания», «Сводка». Отзывы и тексты домашних заданий в отчёт не включаются.
- «Сбросить демо» удаляет только сохранённые данные прототипа на этом устройстве.

## Правила

Время — Екатеринбург, UTC+5. Отметка посещения открыта от начала до окончания занятия. Отзыв принимается в течение 48 часов после окончания. Домашнее задание можно редактировать до проверки, но не позднее окончания курса.

Коллекция: персонаж за отзыв, особые персонажи за 5/10 встреч подряд, за 5 встреч одного формата и за все выполненные задания после окончания курса. Любой пропуск обрывает серию; отменённые занятия не считаются. Серии считаются отдельно для каждого курса. Повторные правки не дают новую награду. После ручного изменения посещаемости серии пересчитываются.

Данные сохраняются в `localStorage` текущего браузера. Не очищайте данные сайта, если хотите сохранить изменения. В режиме инкогнито они могут исчезнуть при закрытии окна. Разные браузеры и устройства не обмениваются данными. При открытии через `file://` поведение хранилища зависит от браузера; надёжнее использовать локальный сервер.

## Граница прототипа

Это демонстрация интерфейса с одним локальным профилем, а не готовая многопользовательская система. Все административные действия доступны на той же странице для проверки. Переключение видимости показывает нужный сценарий, но не создаёт серверной защиты данных. Не вводите реальные персональные или конфиденциальные данные студентов.

Для рабочего сервиса нужны сервер, база данных, проверка почты, разделение прав, Telegram-бот, резервное копирование и защищённое хранение. Авторизация по коду из письма и Telegram в прототипе не имитируются как работающие сервисы. Также пока нет управления несколькими пользователями, создания новых курсов, смены кода группы и фильтрации отчёта по периоду. Занятия существующих демонстрационных курсов редактируются на сайте.

Изображения и логотип взяты из предоставленных владельцем презентаций БРИДЖ. Тексты курсов, имена преподавателей и расписание — демонстрационные.

## Публикация на GitHub Pages

В настройках репозитория: Settings → Pages → Deploy from a branch → main → / (root) → Save. Публичный сайт — демонстрация; реальные данные студентов сюда вводить не следует.
